# ADR-012: Design inspiration e IP boundaries

## Status
Aceito

## Contexto
Spec §0.1 proíbe cópia de RimWorld; inspiração em princíios de gestão de colônia.

## Decisão
Visual "terminal de colônia civil" com tokens próprios (grafite, acentos funcionais). Metáforas de domínio (pawn, colônia, missão) são vocabulário interno, não branding RimWorld.

## Consequências
- Paleta e componentes originais em colony_design_system
- Nomes na UI em português (Colônia, Pawn → personagem/perfil)
