# Keystore de sideload

Assinatura **estável** dos APKs de teste gerados no GitHub Actions.

- **Não** é chave da Play Store.
- Está no git de propósito: builds sucessivos atualizam o app no celular sem desinstalar (e sem perder dados locais).
- Senha e alias são públicos e só servem para consistência de CI. Não use esta chave em release de loja.
